# Portfólio — Alexandre Farias

Portfólio pessoal, bilíngue (PT/EN), feito com React 19 e Vite.
Online em https://portifolio-ten-sigma-11.vercel.app

## Rodando localmente

```bash
npm install
npm run dev      # servidor de desenvolvimento
npm run build    # build de produção em dist/
npm run lint:check
```

## Estrutura

- `src/PageWeb/hello` — hero com pôster e animações
- `src/PageWeb/About` — sobre mim
- `src/PageWeb/Projects` — projetos e trabalhos
- `src/PageWeb/Nen` — teste de Nen (Hunter x Hunter)
- `src/PageWeb/Contact` — chat de perguntas e contato
